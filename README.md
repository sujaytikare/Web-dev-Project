# Attendance Calculator

This is a simple web development project made with HTML, CSS and JavaScript.

## What it does

- Takes total classes
- Takes attended classes
- Takes the required attendance percentage
- Shows the current attendance percentage
- Shows how many classes can be missed
- Shows how many classes need to be attended if attendance is low

## How to run

Open `index.html` in a browser.

## Files

- `index.html` has the page content
- `style.css` has the design
- `script.js` has the calculation code
